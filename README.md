# PrilavokPOS iPad

Локальное iPad POS приложение для кафе.

## Архитектура

- iPad приложение: Swift + WebView
- Backend: Railway
- Database: Supabase

## Правила разработки

1. Не ломать существующий функционал при добавлении новых возможностей.
2. Перед изменением существующего блока проверять зависимости.
3. Новые функции должны учитывать работу на iPad с сенсорным управлением.
4. Дизайн ориентируется на современный POS интерфейс (Loyverse-подобный стиль).
5. Большие кнопки, скругления, простая навигация.

## Процесс разработки

Основная ветка: main

Каждое крупное изменение должно иметь описание:
- что изменено;
- какие файлы затронуты;
- какие риски есть.

## Известные ошибки и решения

### Доставка

Проблема: изменение типа заказа не обновляло связанные расчёты.

Правило: при изменении логики заказа проверять UI, расчёт суммы, сохранение и чек.
