## Follow-up: личное уведомление о новом заказе — 2026-10-04

- В Telegram-настройки добавлены локальные поля `deviceChatId` и `notifyOnlineOrders`; старые записи загружаются с выключенным флагом.
- POS сначала сохраняет настройку локально, затем явным сохранением регистрирует ID и флаг на backend; токен бота остаётся локальным и не передаётся.
- Backend отправляет на личный Telegram ID сообщение `Получен онлайн заказ проверьте POS` сразу после атомарного создания подтверждённого заказа, даже когда POS закрыт.
- ID рабочей группы и темы продолжают использоваться только для прежних групповых отчётов.
- Повторное подтверждение checkout не дублирует сообщение; входящий SSE-поток POS больше не отправляет Telegram-уведомление.
- Полный Node-набор и контрольная simulator-сборка без подписи проходят; интерфейс Telegram проверен в браузере на компактном размере iPad.
