# Results

Реализован запрос актуального снимка открытой смены по инициативе владельца. Backend не хранит продажи: он проверяет владельца, передаёт одноразовый запрос открытому POS и возвращает ответ боту. При закрытом или недоступном POS запрос завершается сообщением об offline-состоянии.

Автоматическая проверка охватывает локальный расчёт, наличные/карту, категории/позиции, авторизацию владельца, таймаут и совместимость миграции. Физическая проверка остаётся после установки новой сборки.
