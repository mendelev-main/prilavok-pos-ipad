# Feature Specification: Warehouse report presentation

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Завершить стандартизацию статического представления складского отчёта, используя общий футер модального окна без изменения расчётов и экспорта.

## User scenarios

1. Администратор открывает формирование складского отчёта и видит стандартно расположенные действия.
2. Администратор выбирает разделы и формат PDF или Excel с прежним результатом.
3. Окно остаётся читаемым в светлой и тёмной темах.

## Requirements

1. `warehouse-reporting.js` не содержит inline style attributes.
2. Действия окна формирования отчёта используют общий `.modal-actions`.
3. Выбор разделов, формата, период и экспортный payload не меняются.
4. Права администратора и native export bridge не меняются.
5. Полная автоматизированная матрица и simulator build проходят.

## Success criteria

- В модуле складского отчёта остаётся 0 inline style attributes.
- Кнопки не выходят за границы модального окна в обеих темах.
- Существующие warehouse tests проходят.

## Out of scope

- Изменение складских расчётов.
- Изменение PDF или Excel документов.
- Изменение состава и названий разделов отчёта.
- Изменение прав доступа.
