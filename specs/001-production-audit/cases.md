# Матрица проверки приложения

Baseline: [results.md](results.md). Все строки физической приёмки относятся к новой проверяемой сборке.
AUTO = существующие тесты покрывают указанный сценарий или его часть, не end-to-end на устройстве.
FAIL = дефект воспроизведён; «Код» = установлен статическим обзором; OPEN = ещё не выполнено.
Ни один AUTO не разрешает закрывать физическую приёмку без фактического прогона.

Для каждой строки при прогоне добавить: дату, build, устройство, фактический результат,
ID тестовых документов, PASS/FAIL и ссылку на находку. Порядок: S/P/H → C/N/R → W/L → A/B → E/T/U.
