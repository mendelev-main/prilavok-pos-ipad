# Feature Specification: Catalog and navigation presentation

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Перевести статическое оформление каталога товаров и навигации рабочей зоны на именованные классы, сохранив поиск, сортировку, папки и расположение плиток.

## User scenarios

1. Администратор ищет и сортирует товары, очищает поиск и открывает карточку товара без изменения поведения таблицы.
2. Кассир открывает категории и папки и видит прежнюю адаптивную сетку товаров.
3. Администратор включает режим раскладки, добавляет и перемещает плитки, а сохранённые координаты и цвета остаются прежними.

## Requirements

1. `product-catalog.js` не содержит inline presentation rules.
2. Видимость строк поиска, таблицы, empty state и кнопки очистки управляется стандартным `hidden` contract.
3. Статическое оформление `pos-navigation.js` задаётся именованными классами.
4. Inline styles в навигации допустимы только для сохранённых grid coordinates и пользовательского category color.
5. Форматы `layout` и `posNavigation`, их ключи, запись, drag-and-drop и действия с товарами не меняются.
6. Полная автоматизированная матрица и simulator build проходят.

## Success criteria

- В каталоге остаётся 0 inline style attributes.
- В навигации остаются только 2 проверяемых динамических style templates: координаты плиток и цвет категории.
- Существующие тесты поиска, сортировки, папок и drag-and-drop проходят.
- Light/dark browser smoke-check не выявляет переполнения или скрытых controls.

## Out of scope

- Изменение данных товаров или раскладки.
- Новый дизайн карточки товара.
- Изменение количества колонок рабочей зоны.
- Рефакторинг drag-and-drop runtime.
