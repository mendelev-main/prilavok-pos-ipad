# Feature Specification: Design system foundation alignment

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Устранить безопасные системные расхождения `DS-01`, `DS-03`, `DS-07`, `DS-08` и `DS-11`, не меняя бизнес-логику, данные и сетевые границы POS.

## Requirements

1. Все статические CSS variables должны быть объявлены; исторические `--text` и `--line` заменяются действующими `--ink` и `--border`.
2. Интерфейс использует только загруженные веса Manrope 400–800.
3. Основные зелёные кнопки используют `--accent-ink` в обеих темах.
4. Часто используемые компактные контролы получают touch-зону не меньше 44×44 px либо эквивалентную расширенную hit area.
5. Button-based WEB switches имеют `role="switch"`, доступное имя и актуальный `aria-checked`.
6. Нативные checkbox switches остаются доступными для focus и assistive technologies.
7. Добавляются semantic success/warning/info/control-off tokens для обеих тем; существующие основные статусы переводятся на них.
8. Storage, сеть, оплата, чеки, смены, печать и формат данных не меняются.

## Acceptance

- Проверка неизвестных tokens не находит ошибок.
- В production UI отсутствуют `font-weight: 750`, `850` и `900`.
- Все автоматизированные тесты проходят.
- Физическая визуальная проверка отложена до общего ручного прогона.
