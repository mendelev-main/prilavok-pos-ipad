# Feature Specification: полная локальная резервная копия M POS

## Цель

Дать сотруднику возможность вручную сохранить на другое устройство единый файл, достаточный для
восстановления рабочего POS после поломки или замены iPad. Копия создаётся только по кнопке и не
добавляет облачную синхронизацию, таймеры или фоновые сетевые операции.

## Требования

- Экспорт доступен в настройках и использует системное меню iPad «Поделиться»/«Файлы».
- Schema v13 включает все прикладные локальные данные: товары, рецептуры, остатки, категории,
  папки и плитки, сотрудников, смены, чеки, заказы, приёмки, поставщиков, инвентаризацию,
  текущий заказ, сохранённый черновик приёмки, журнал принятия WEB-заказов, настройки приложения,
  сети, Telegram и принтеров.
- По явному решению владельца копия включает `deviceKey`, Telegram bot token и другие локальные
  параметры подключения. Интерфейс обязан сообщать, что файл содержит конфиденциальные данные.
- Нативные фотографии товаров входят в тот же файл. При импорте им назначаются новые локальные ID,
  чтобы подготовка восстановления не перезаписывала действующие изображения.
- Импорт сначала читает и валидирует весь файл, затем показывает дату и объёмы данных. До явного
  подтверждения локальное состояние не изменяется.
- Восстановление storage выполняется через существующий `criticalStorageJournal`. Ошибка проверки
  или записи не должна частично менять runtime.
- Если восстановление storage не удалось, подготовленные фотографии удаляются. После успеха
  остаются только изображения, на которые ссылаются восстановленные товары.
- Старые резервные копии версий 1–12 остаются совместимыми и получают прежние значения по умолчанию.
- Формат localStorage и существующие ключи не переименовываются.
- Экспорт и импорт никогда не запускают синхронизацию с backend.

## Проверка

- Автотест подтверждает наличие всех локальных настроек в schema v13 и их round-trip.
- Автотест подтверждает совместимость v11/v12 и отказ от повреждённых разделов до записи.
- JavaScript и Swift проходят доступные статические проверки, полный Node suite и iOS build.
- Финальная приёмка выполняется на физическом iPad: экспорт в Files, импорт на чистую установку,
  проверка товаров, связей, папок, чеков, смен, приёмок, настроек и фотографий.
