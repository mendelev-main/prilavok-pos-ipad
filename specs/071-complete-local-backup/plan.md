# Implementation Plan

1. Зафиксировать полный перечень логических storage-ключей и поднять формат резервной копии до v13.
2. Сохранить импорт v1–v12 и применять восстановление через существующий critical journal.
3. Добавить нативный iOS bridge для системного экспорта, выбора файла и переноса JPEG товаров.
4. Дать резервной копии отдельный понятный вход в настройках и явно отметить наличие секретов.
5. Покрыть полный round-trip, legacy-совместимость и нативную границу автоматическими проверками.
6. После установки пройти восстановление на физическом iPad по чек-листу production audit.
