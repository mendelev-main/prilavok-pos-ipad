# Feature Specification: Product configuration presentation

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Стандартизировать статическое оформление конфигурации товаров, рецептур, модификаторов и категорий без изменения продуктовых данных и вычислений.

## User scenarios

1. Администратор настраивает единицы, закупочную конфигурацию и остатки простого товара в прежнем рабочем сценарии.
2. Администратор редактирует составной товар, выход рецептуры и модификаторы с единообразными карточками и полями.
3. Администратор создаёт или редактирует категорию, выбирает цвет и управляет публикацией в WEB без изменения сохранённых значений.

## Requirements

1. `product-configuration.js` не содержит inline presentation rules.
2. Статическое оформление `product-categories.js` задаётся именованными классами.
3. Inline styles категорий допустимы только для динамического `--category-color` сохранённой категории и элемента палитры.
4. Единицы, пересчёты, рецептуры, модификаторы, category rename и storage writes не меняются.
5. Полная автоматизированная матрица и simulator build проходят.

## Success criteria

- В product configuration остаётся 0 inline style attributes.
- В categories остаются только 2 проверяемых dynamic color templates.
- Тесты единиц, рецептур, модификаторов и категорий проходят без регрессий.
- Light/dark browser smoke-check не выявляет переполнения controls.

## Out of scope

- Изменение модели товара или формата рецептуры.
- Изменение доступов администратора.
- Новые единицы измерения или варианты модификаторов.
- Редизайн общего product editor shell.
