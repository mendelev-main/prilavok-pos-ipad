# Feature Specification: отдельные каналы онлайн-каталога

**Roadmap**: R4

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Разделить публикацию товара в онлайн-заказ и в меню для просмотра, сохранив существующие локальные
товары, ручную синхронизацию каталога и offline-first работу POS.

## User scenarios

1. Администратор включает «Онлайн меню» и выключает «Онлайн заказ»: товар виден в меню, но его нельзя заказать.
2. Администратор вводит описание товара в онлайн-разделе: после ручной синхронизации описание видно в карточке на обеих веб-страницах.
3. После обновления старые товары остаются видимыми в меню, а их прежний признак онлайн-заказа не меняется.
4. Ошибка backend не мешает сохранить товар локально и не запускает автоматическую синхронизацию каталога.

## Requirements

1. Существующий локальный ключ `availableOnline` сохраняется и получает подпись «Онлайн заказ».
2. Новый локальный ключ `availableInOnlineMenu` независимо управляет видимостью в меню для просмотра.
3. Старый товар без нового ключа получает `availableInOnlineMenu: true`; `availableOnline` сохраняет прежнее значение.
4. Новый товар сохраняет прежнее начальное состояние формы; импортированный товар не публикуется ни в одном онлайн-канале.
5. Поле `description` редактируется в онлайн-разделе и сохраняется в существующем JSON товара.
6. Полная публикация флагов и описания происходит только существующей ручной синхронизацией меню.
7. `/api/menu` возвращает товары онлайн-заказа; `/api/menu?surface=menu` возвращает товары меню для просмотра.
8. Backend migration сохраняет все строки и задаёт существующим товарам видимость в меню.
9. POS остаётся источником истины; backend не изменяет локальный каталог.
10. Storage failure не публикует новое состояние, network failure не отменяет локальное сохранение.

## Success criteria

- Два переключателя можно сохранять независимо.
- Описание до 2000 символов проходит POS → manual sync → backend → обе веб-карточки.
- Старые товары не исчезают после обновления.
- Автотесты POS, backend и миграции проходят; JavaScript syntax и Simulator build успешны.

## Out of scope

- Автоматическая синхронизация каталога.
- Отдельные категории для двух веб-страниц.
- Изменение availability snapshot, checkout или складских расчётов.
