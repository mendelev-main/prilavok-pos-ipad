# Feature Specification: Design system audit

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Зафиксировать фактический визуальный язык M POS в постоянной документации и найти элементы, которые выбиваются из него, без изменения рабочего интерфейса и бизнес-логики.

## Requirements

1. Документ описывает палитру обеих тем, типографику, отступы, радиусы и поверхности.
2. Документ описывает кнопки, поля, переключатели, варианты выбора, карточки, списки, таблицы, статусы, модальные окна и адаптивность.
3. Правила основаны на текущей реализации `pos.html` и feature-модулей.
4. Все найденные расхождения перечислены с предлагаемым направлением, но не исправляются без отдельного решения.
5. Аудит не меняет storage, сеть, UI runtime и native code.

## Acceptance

- `docs/DESIGN_SYSTEM.md` доступен из индекса документации.
- Каждое заметное расхождение можно найти по стабильному ID `DS-*`.
- Изменённые файлы являются только документацией и Spec Kit metadata.
- `git diff --check` проходит.
