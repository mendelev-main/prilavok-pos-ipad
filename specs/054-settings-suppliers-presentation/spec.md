# Feature Specification: Settings and suppliers presentation

**Roadmap**: R12

**Baseline**: M POS 130.54

**Date**: 2026-10-02

## Goal

Стандартизировать основную страницу настроек, панель администратора и редактор поставщика без изменения прав доступа, локальных данных и операций поставщиков.

## User scenarios

1. Сотрудник открывает настройки и видит единообразные секции сотрудников, поставщиков, доставки и скидок.
2. Администратор открывает панель администратора и переходит в существующие разделы через одинаковые карточки.
3. Администратор создаёт или редактирует поставщика, ищет и выбирает закреплённые товары в прежнем сценарии.

## Requirements

1. `suppliers.js` не содержит inline style attributes.
2. Статическое оформление settings shell и admin navigation задаётся именованными классами.
3. Фильтрация товаров поставщика использует стандартный `hidden` contract.
4. Ключ `suppliers`, структура поставщика, проверки доступа и порядок storage writes не меняются.
5. Полная автоматизированная матрица и simulator build проходят.

## Success criteria

- В `suppliers.js` остаётся 0 inline style attributes.
- Основная страница настроек и редактор поставщика корректны в обеих темах.
- Создание, изменение, удаление и поиск поставщика проходят без регрессий.

## Out of scope

- Изменение сетевых настроек, Telegram или принтера.
- Новые поля поставщика.
- Изменение ролей и разрешений.
- Изменение storage schema.
