# Runtime Boundary Contract

Модуль предоставляет существующие global functions для editor, catalog и inline delete checks.
Он не запускается самостоятельно, не устанавливает таймеры и не выполняет сеть при загрузке.
Сеть разрешена только внутри явно вызванного `saveProduct` и только после успешной локальной записи.
